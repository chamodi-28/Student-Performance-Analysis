# Student Performance Analysis Dashboard

## Overview
This project analyzes student academic performance using Microsoft Power BI. It helps to understand students' marks, attendance, pass rates, and subject-wise performance through an interactive dashboard.

## Dashboard Screenshot

![Student Performance Dashboard](docs/Screenshot.Jpg)

## Features
- Total number of students
- Average marks
- Student pass rate
- Average attendance
- Subject-wise performance analysis
- Student-wise marks comparison
- Interactive filters for subject and gender

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Purpose
The main purpose of this project is to practice data analysis and visualization skills using Power BI and gain insights into student academic performance.
